# 0001 — 起点：SGRT 领域专家，但 agent 设计零基础

用户是 SGRT（放疗表面追踪）工程专家，对自身系统了如指掌（相机随机架转动、标定板±30°、外参 X/轴/δ 求解、床板QA 2mm/1°、ICP胸腹表面配准）。但**在 agent 领域是小白**：只用 agent 写过代码，不懂得系统化"设计"。目标：学会设计 agent，用于 SGRT 的标定引导/自动标定、故障排查、日常 QA。

Evidence: 用户自述"我就是个小白……只用来写代码，不知道该怎么设计……想学会设计agent系统然后用于SGRT的标定引导/自动标定、故障排查、日常QA等环节"。早期"写了笔记=已掌握"的判断已被用户纠正（覆盖≠领会）。

Implications（决定教学怎么走）:
- 从"设计 agent 的整套思维"零基础教起，不预设理论功底。
- 理论讲完必须立刻落到 SGRT 环节，否则对用户无意义。
- 先教"判断 task → 选 workflow/agent → 选组件 → 搭最小可评估原型 → 评估"这条设计主线。
- 用户既有工程直觉极强：用他熟悉的 SGRT 术语做桥，能大幅降低学习门槛（呼应 NOTES.md 的偏好）。
- 第一个实战对象建议挑结构化、易出成果的：SGRT 标定 QA 或日常 QA（先 workflow），故障排查作为"真 agent"进阶目标。
