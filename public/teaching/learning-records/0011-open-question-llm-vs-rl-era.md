## 题目
**"LLM 时代"相比"RL 时代"，给 agent 带来的最本质变化是什么？**

## 落点
- 文件：`综合题/开放题库/精选02-LLM时代vsRL时代.md`（★★★）
- 沿用精选题格式：精选理由 / 题目 / 我的作答 / 参考解析 / 评判关注点 / 延伸关联网。

## 内容要点（核心答案）
- **根**：agent 的"策略/能力"从**必须训练进参数** → 变成**可用自然语言在运行时指定**。
  一句话："RL 时代'学会'= 更新参数；LLM 时代'学会'= 改上下文。"
- **连锁效应**（对比维度）：能力获得方式、策略载体、换任务成本、泛化、交互原语、人的介入、门槛。
- **精确补刀**（本题区分度所在）：LLM 时代**没有淘汰 RL**——
  RL 从"agent 的构造手段"**退位为"模型的训练手段"**。答"淘汰 RL"扣分。
- **落项目**：Bps Copilot 的策略在 system prompt + ToolRegistry + 运行时判断三处，
  改行为 = 改 prompt/加工具，**不训练**。
- **深一层加分**：能力获取的接口从"梯度"变成"上下文"。
