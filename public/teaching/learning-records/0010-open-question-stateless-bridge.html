精选题 01 内容要点

  • 只给一个事实（"大模型本身无状态"），要求倒推一根架构承重柱。
  • 根：上下文管理（外部状态重放）。
  • 墩（缺口→机制→项目对应）：不记上轮→会话历史缓冲；工具结果会丢→tool 回填； 不记进度→外部持久化；重启即忘→磁盘证据重建（Pose_*.bmp 推断）；跨会话无记忆→长期记忆/RAG； 附：上下文有限→token 裁剪。
  • 追问：为什么每轮发全量历史（模型看不到上一轮）→ 逼出上下文窗口约束 / context engineering。
  • 加分：本质 = "无状态计算 + 外部状态存储 = 有状态行为"；先例 = HTTP 无状态+session / REST / 函数式编程显式 state。
  • 附「延伸关联网」：把题目能牵出的 L1/L2/L4/RAG 画成树。

为什么单独拎出（用户意图）

  • 这题跨讲、承重、可回味、有工程落点，性质是"精选题"而非"某讲专项题"。
  • 开放题库与"按讲结业考试"分工：后者考"这讲学会没"，前者考"能不能把几讲串成网"。
