LangGraph：用"状态 + 节点 + 边"画一张可执行的工作流

第 41 课（Lecture05 第 3 课）· 来源：lecture05.pdf p52-77 · 本课成果：掌握 LangGraph 的三个原语（共享 State、读写的 Node、定流向的 Edge 含条件边），并能用它把 workflow 画成图、把 agent 画成"LLM↔工具"环

先给结论

LangGraph 的抽象是图（Graph）：State 是共享工作区（可理解为图会修改的对象）、Node 是读写 State 的函数、Edge 定义控制流（有些是条件边，实现分支）。

一句话对照 DSPy：DSPy 用"签名+模块"（声明 What/How），LangGraph 用"状态+节点+边"（显式画控制流）。前者偏"自动优化提示"，后者偏"手工编排流程"。

三原语（p53-57）

State:  共享工作区（图会修改的对象）
Start ─► Node ─► Node ─► End      （每个图都要有 Start 和 End 节点）
                │
                └─► Node         Edge 定义控制流；部分 Edge 是"条件边"（分支）
原语是什么课件原话
State共享工作区"可以把它想成图会修改的一个对象"
Node读写 state 的函数"Nodes are functions that read and write to/from the shared state"
Edge定义控制流"Edges Define Control Flow；Some Edges are Conditional"

每个 Graph 都需要 Start 和 End 节点。

用图表达一个 Agent（p58, p73-75）

State（可以是消息历史）
Start ─► LLM ─► Tools ─► LLM ─► … ─► End
           ▲              │
           └──────────────┘   （LLM 决定调工具 → 工具返回 → 再回 LLM）

p58 的"Outline of a LangGraph Agent"正是这个环：State 可为消息历史，节点是 LLM 和 Tools，边构成"LLM→工具→LLM"的循环——这就是 Week1 第 5 课的 agent loop 在图上的样子。

LangGraph 总结（p76，原文）

• LangGraph 在图上操作共享 state；
• Nodes 读写 state；
• Edges 定义节点间控制流；
• 有些边可以是条件边（实现分支工作流）；
• LangGraph 有内置工具来创建 agent：create_agent。

与 DSPy 的对照（p77 小结）

DSPyLangGraph
核心抽象签名（What）+ 模块（How）+ 优化器State + Node + Edge
关注点声明契约 + 按指标自动优化显式编排控制流（含条件分支）
适合想让框架自动调提示/权重想手工画清流程与分支

课件小结原文：workflow 把"模型调用、工具、程序逻辑"组合成更大的 AI 系统；框架暴露不同抽象——DSPy 用签名与模块，LangGraph 用 state/nodes/edges。

对你 SGRT 系统的含义

  1. 画得清就是好设计：把你的"标定 QA 流程"（拍照→提取→算残差→对阈值→出报告）画成 LangGraph 图，天然就是可执行、可检查的 workflow。
  2. 条件边=你的判定点："残差超 2mm 就走告警分支，否则走通过分支"——条件边正是这个。
  3. agent 也是图：排查 agent 的"LLM→工具→LLM"环，用图表达后循环与终止条件一目了然（配合 Week3 的停止规则）。

自测（先答再展开）

Q1. LangGraph 三原语是什么？各干什么？

展开答案

State（共享工作区/图会修改的对象）、Node（读写 state 的函数）、Edge（定义控制流，部分为条件边实现分支）。

Q2. 一个 LangGraph Agent 的图长什么样？State 常用什么？

展开答案

Start→LLM→Tools→LLM→…→End 的环：LLM 决定调工具、工具返回结果再回 LLM。State 常用消息历史。

Q3. 条件边有什么用？给你的 SGRT 举个例。

展开答案

实现分支工作流。例："残差超 2mm → 告警分支；否则 → 通过分支"。

Q4. DSPy 和 LangGraph 的核心抽象差别？各适合什么？

展开答案

DSPy：签名+模块+优化器，适合让框架自动优化提示/权重；LangGraph：State+Node+Edge，适合手工编排控制流与分支。
