智能体从哪来：五十年的一条线

第 4 课（共 13 课）· 重建 v3 · 本课成果：能按时间段讲出 agent 概念的来历，并说出“agent 四性”是什么 · 知道脉络即可，不用背年份

先给结论

“智能体”不是 2022 年才有的新词。核心思想五十年没变：一个能自主感知环境、自己决定行动、并朝着目标推进的东西。LLM 做的，只是终于给这个老概念装上了一颗能“推理”的大脑。

一条时间线（看趋势，不必背年份）

时期关键事件留下的思想
1990 之前词源拉丁 agens（“行动者”）；1973 ACTOR 形式化（Hewitt 等）；1980 Contract Net（智能体间协商任务）；1986 Minsky《心智社会》“行动者”与“多个体协作”的概念雏形
1990 年代Wooldridge & Jennings（1995）定义 agent 四性；Russell & Norvig（1995）定义“通过传感器感知、通过执行器行动”agent 四性与“感知-行动”范式
强化学习时代agent–environment 循环（Sutton & Barto, 1998）；DQN 打通 Atari（Mnih 2015）“循环”与“从反馈中学习”
LLM 时代GPT-3 带出 in-context learning（2020）模型第一次能“零训练”地听指令、举例学

爆发时间线（2022–2023，记住顺序即可）

2022-10    ReAct（推理+行动，第 5 课的“环”从这里来）
2022-11-30 ChatGPT 发布
2023-03-14 GPT-4
2023-03-28 BabyAGI
2023-03-30 AutoGPT

短短半年，“LLM 自己规划、自己调工具干活”从一篇论文变成全民玩具。这个加速度，就是这门课存在的理由。

agent 四性（1995 年的定义，今天依然成立）

性质含义SGRT 里的影子
自主性 autonomy没人盯着也能自己推进自动标定流程自己跑完并出报告
社交性 social ability能与其他 agent/人交互协作多个工具/模块协同（标定+配准+报告）
反应性 reactivity能对环境变化及时响应检测到残差超阈值立即转人工
主动性 proactivity能主动朝目标采取行动，而非被动等指令主动巡检历史标定、发现漂移趋势
读法：今天你在设计 agent 时反复问的“它该有多大自主权”，本质就是 1995 年这四个性质在 LLM 语境下的重新表述。

自测

Q1. 智能体的“环”（agent loop）最早出自哪篇工作？

展开答案

ReAct（Yao et al., 2022）。Obs→Think→Act 的循环是第 5 课那张核心架构图的来源。

Q2. agent 四性是哪四条？

展开答案

自主性、社交性、反应性、主动性（autonomy / social ability / reactivity / proactivity），出自 Wooldridge & Jennings 1995。

Q3. “LLM 时代”相比“RL 时代”，给 agent 带来的最本质变化是什么？

展开答案

RL 时代的 agent 靠大量试错学习、策略是隐式的；LLM 带来了用自然语言推理和调用工具的能力，于是“规划”第一次可以用语言直接表达和检查（这也让可靠性/对齐成为新问题）。
