模型是怎么造出来的：预训练 → 中训练 → 后训练

第 16 课（Week2 第 3 课）· 来源：lecture02.pdf p92-118 · 本课成果：分清三段各在干什么、数据为什么是核心、RLHF 的坑与 RLVR 的破法，以及"agent 专用训练"是什么

先给结论

一个能当 agent 大脑的模型，分三段炼成：预训练（啃海量网页，学语言与世界常识）→ 中训练（把数据配比往目标领域倾斜，如数学/代码）→ 后训练（指令微调 + 人类偏好对齐，让它"听话又好用"）。

对你的工程含义：后训练决定"性格与对齐"，预训练/中训练决定"下限与领域知识"。你选模型做 SGRT 排查，领域能力来自中/预训练，而"是否老实、是否会瞎编"来自后训练——两者要分开评估。

第 0 步：损失函数（p93-100）

训练目标=抬高"数据里真实下一个词"的预测概率。用交叉熵：

Loss = - log P(正确词)
例：P(how | The class was about) = 0.0124
    Loss = -log(0.0124) = 1.907

直白说：正确词概率越高，Loss 越小；训练就是不断把 Loss 压下去。

第 1 段：预训练 Pretraining（p101-107）

目标：从原始网页里炼出"干净、量大、高质量"的语料。管线（p102 数据管线图）：

HTML → 文本抽取 → 去重 → 语言识别(Lang ID) → 规则过滤 → 质量过滤 → 最终训练数据
  • 数据质量就是模型上限。p103 (DataComp-LM)、p104 (Nemotron-CC-Math)、p106 (The Pile) 都在讲同一件事：不同数据配比直接决定模型能力。
  • 数据混合 Data Mixing（p107）：不同来源按什么比例混，是门正经学问。

第 2 段：中训练 Midtraining（p108-111）

目标：不重训，只调整数据配比，往目标领域倾斜（数学、代码等）。

  • p109：把数据 mix 改成更聚焦目标领域。
  • p110《The Finetuner's Fallacy》：把目标领域数据"混进预训练"往往比只做微调更有效。
  • p111：中训练是连接预训练与后训练分布之间的桥。
工程桥：这就像你的标定流程里，不必推倒重来重训整个模型，而是"用一批贴近真实工况（不同体型/呼吸幅度）的数据补一轮中训练"，让模型在你关心的分布上更稳。

第 3 段：后训练 Posttraining（p112-118）

① 指令微调 Instruction Finetuning（p113）

用"指令→好答案"的样例教模型"听懂话、按格式答"（Scaling Instruction-Finetuned LMs）。

② 人类偏好对齐 RLHF（p114）

让人对多个回答排序，训练奖励模型，再用 RL 优化（InstructGPT, 2022）。

③ 人类反馈的坑（p115）

  • 标注者不可靠、口味不一；
  • 诱导出坏激励——谄媚（sycophancy）、装权威。

④ RLVR：让奖励可验证（p116）

Reinforcement Learning with Verifiable Rewards：把奖励做成能"自动判对错"的——单元测试、Lean 证明、精确匹配。数学和代码尤其适用。注意验证器本身的设计（否则会被刷分）。

⑤ Agent 专用训练（p117-118）

用 SWE-Smith 这类方法，批量合成"软件工程 agent"的任务轨迹来训 agent 能力。意义：agent 能力可以被专门数据"练"出来，而不只是提示词堆出来。

三段一句话对照

阶段输入产出/目的对你选型的意义
预训练海量网页语言/世界常识决定基础智力下限
中训练领域配比数据领域能力强化决定你关心的领域（如医学文本）好不好
后训练指令/偏好/可验证奖励听话、对齐、行为风格决定"是否会瞎编、是否老实"

自测（先答再展开）

Q1. 三段训练各自的核心目标是什么？

展开答案

预训练=学语言与世界常识（吃海量网页）；中训练=调数据配比往目标领域倾斜；后训练=指令微调 + 偏好对齐，让模型听话、行为可控。

Q2. RLHF 会导致哪类坏激励？为什么会这样？

展开答案

谄媚（sycophancy）与装权威等。因为人类标注不可靠、口味不一，模型学会"讨好评判者"而非"说真话"，于是产生坏激励。

Q3. RLVR 是什么？特别适合哪类任务？要注意什么？

展开答案

用可自动验证的奖励做 RL（单元测试、Lean 证明、精确匹配等）。特别适合数学和代码。要注意验证器的设计——验证器有漏洞就会被刷分。

Q4. 你的 SGRT 排查助手偶尔"一本正经瞎编处置步骤"，问题更可能出在哪一段训练？

展开答案

更可能出在后训练（对齐/偏好）——它决定"是否会瞎编、是否老实"。领域知识好不好更像中/预训练的事。所以对策是：接入检索（把事实约束在资料里）+ 后训练更强调可验证奖励的模型。
