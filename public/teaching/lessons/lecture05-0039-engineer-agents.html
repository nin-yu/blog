"工程化"一个 Agent：从"能跑"到"可维护"

第 39 课（Lecture05 第 1 课）· 来源：lecture05.pdf p4-18 · 本课成果：理解"工程化 agent"的四个环节，记住三支柱 Data/System/Eval，并能把框架对照到"模型→workflow→agent"这条能力谱系上

先给结论

本讲主题是框架与编排（Frameworks & Orchestration）。核心判断：框架帮你抽象掉底层细节（就像 PyTorch 之于手写反向传播），方便上手、但会掩盖 system 细节——所以用框架的同时必须知道"底层在发生什么"。

两条主线：(1) 三支柱 Data / System / Eval——任何 AI 系统都绕不开；(2) 能力谱系——模型 → workflow（复合系统）→ agent，框架对每一档都有对应工具。

框架的定位：像 PyTorch 之于反向传播（p4-5, p6）

手写 Backprop用 PyTorch
优点完全掌控细节抽象掉底层、上手快
代价繁琐看不清底层在干什么

课件的态度：框架抽象掉一些系统细节；但本课程要求你"实现/理解系统细节"，今天的目标是理解这些抽象。

学习目标（p6）

  1. 识别 agent 系统工程中常见的框架；
  2. 把这些框架引入的抽象，对应回课程里讲过的底层系统设计；
  3. （以及本讲后续）在实践中做出工程取舍。

三支柱：Data / System / Eval（p10-12）

支柱包含
Data训练数据、rollouts（执行轨迹）、示范、人类反馈…
System / Model语言模型、复合 AI 系统/workflow、agentic 系统…
Eval指标与评测（本课程反复强调的"评估先于建设"）

课件列出课程主线：Introduction（什么是 agentic systems）→ LLMs for Builders → RAG → Tool Use & Function Calling → Frameworks & Orchestration（本讲） → Agent Design Patterns & Scaffolds → Agent Memory Architecture → …

框架谱系（p14-17）

Model  ────────►  Workflow / Compound AI System  ────────►  Agent
"逻辑与编排            "逻辑与编排               "控制流的角色
 在程序外部"            在程序里"                 归 AI 模型"
OpenAI API 等           DSPy, LangGraph…          各种 agent harness
  • Model 档：模型只是更大系统的一小部分，逻辑/编排在程序外部（如直接调 OpenAI API）。
  • Workflow 档：逻辑与编排"活在程序里"（DSPy、LangGraph）。
  • Agent 档：控制流的角色归 AI 模型（各种 harness）。

p17 抛出问题："这些框架真的被用吗？"——引出后面 DSPy/LangGraph/harness 的实际讨论。

对你 SGRT 系统的含义

  1. 先问"要不要框架"：你的标定 QA 是固定管线，可能要的不是框架而是几十行代码（Week2 第 22 课"最简优先"）。
  2. 用框架就查底层：如果用了 LangGraph/DSPy，务必知道它每次调用到底发了什么提示——否则排障时会瞎。
  3. 三支柱都要有：别只搭 System，忘了 Data（评测集）和 Eval（指标）。

自测（先答再展开）

Q1. 课件用什么类比说明"框架"的作用？代价是什么？

展开答案

类比 PyTorch 之于手写反向传播：框架抽象掉底层系统细节、上手快；代价是看不清底层在发生什么，所以必须理解这些抽象背后的系统细节。

Q2. 三支柱是哪三个？各含什么？

展开答案

Data（训练数据/rollouts/示范/人类反馈）、System or Model（语言模型/复合系统/agentic 系统）、Eval（指标与评测）。

Q3. 框架谱系三档分别是什么？控制流归谁？

展开答案

Model（逻辑在程序外部，如 OpenAI API）→ Workflow/复合系统（逻辑在程序里，如 DSPy/LangGraph）→ Agent（控制流归 AI 模型，各种 harness）。

Q4. 你的标定 QA 系统，要不要上框架？怎么判断？

展开答案

先判范式：固定管线（步骤已知）用几十行代码可能就够，不必上框架；只有确实需要复杂编排/优化时才引入，并确保理解框架底层发了什么。
