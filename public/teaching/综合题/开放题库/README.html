定位：跨讲、跨主题的开放题库，独立于按讲分的 综合题/Lecture01…05/。 这里收的是——打通多讲概念、能反复回味、一题牵出一片知识网的精选式深挖题。 规则：题目 + 「我的作答」区（你自己写）+ 「参考解析」（评卷用）+ 「延伸关联网」（这题能牵出哪些课）。 与结业考试的区别：结业考试考"这一讲你学会了吗"；精选题考"你能不能把几讲串成一张网"。

主题簇：五题同根——能力从哪来、存在哪、为什么不可全信、值不值、为什么要闭环。 精选01 记忆从哪来 · 精选02 策略从哪来 · 精选03 可信度从哪来（工具+护栏）· 精选04 推理从哪来/值不值（能力放大器，非事实来源）· 精选05 推理为什么要闭环（Observation=事实接口）。

收题标准（什么样的题够格进"精选"）

  1. 承重性：它考的是一个"架构根"，不是某个名词定义。答对了，你就理解了半个 agent 设计。
  2. 串联性：一题能牵出 3 讲以上的概念，迫使你把孤立知识点连成网。
  3. 可回味：不是一次性事实题，隔一段时间重答会有新理解。
  4. 有工程落点：能对到你自己的项目（BPS Copilot / Trio-Track）上，不是纯纸上谈兵。

作答与评卷

  • 每题一个 .md，「我的作答」区留给你直接编辑。
  • 答完（哪怕只答一题）说"评卷"，我按每题末尾「参考解析」+「评判关注点」逐条对。
  • 铁律不变：覆盖 ≠ 领会，写下来的才算证据。
