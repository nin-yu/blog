评判标准（所有题通用）

  • ✅ 说对了、并且能解释为什么 → 说明真懂了。
  • ⚠️ 只说对了名词、说不出为什么 → 还在背概念（我会指出来）。
  • ❌ 有设计漏洞（该上 agent 却选了纯 workflow、漏了安全护栏、没定指标就动手）→ 我会标出来并解释。

提醒

  • 覆盖 ≠ 领会：读过课不算数，写下来的才算证据。
  • 不确定的地方写出你的犹豫和取舍过程——那正是我最想看的设计思维。
  • 每讲正文最后一课都有"综合结业考试题"入口，也可从本页直接领取。
  • 新增一讲时：在 综合题/LectureNN/ 放该讲结业考试 .md，并在该讲最后一课加入口块。
