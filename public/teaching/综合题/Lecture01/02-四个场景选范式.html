题 2 · 四个场景选范式（★）

考点：四问法 + 判定法则（Lesson 12）。每个场景判断该用 workflow / agent / 混合（固定管线+LLM 判断点），并写清为什么——四问法过一遍，不能只给结论。

评判关注点（评卷时用）

  • A：步骤完全固定、结果可枚举 → workflow（LLM 至多做报告摘要）。
  • B：路径未知、观察决定下一步 → agent。
  • C：结构相对固定 → workflow（模板填充）；若说 agent 要给出强理由。
  • D：没有唯一正确答案——"固定聚类管线 + LLM 写分析"的混合最合理；纯 agent 判定要检查是否考虑了成本和可复现性（聚类结果要可复现，LLM 自由发挥会伤一致性）。
