题 3 · agent loop 走一遍（★★）

考点：五大组件 + Obs→Think→Act→Obs 循环（Lesson 5、6）。 任务：下面这条真实感故障，请你以"设计者"身份写出 agent 的完整执行轨迹——每个 Think/Act/Obs 各一句，共 6-8 步，直到 Finish。工具箱里只有这些：read_log（只读）、search_doc（查错误码表/手册）、search_history（查历史工单）、calc（计算器）。

题目

输入故障：今日晨检发现 ICP 配准残差 RMS 从平时的 0.4mm 涨到 1.2mm，最近 3 天持续走高，其余 QA 项正常。

写出 agent 的轨迹（格式参考 ReAct 论文）：

Obs 1: ____
Think 1: ____
Act 1: ____
Obs 2: ____
Think 2: ____
Act 2: ____
...
Finish: ____（最终给操作工的建议）

另外回答：

  1. 这条轨迹里，Memory 组件体现在哪？（traces so far 是什么）
  2. 如果第 2 步的观察是"标定参数三天前被人为改过"，你的 agent 该如何反应？（考察：踩在证据上修正方向，不迎合预设）
  3. 你给这个 agent 的"终止条件"设成什么？（考察：防止无限循环/提前烂尾）

评判关注点（评卷时用）

  • 轨迹是否真的"后步踩前步观察"（每条 Think 引用上一条 Obs 的内容），而不是预先写好的固定剧本。
  • 是否先查数据/日志再下结论（ReAct 精神），而不是开局就猜"标定漂了"。
  • Memory=轨迹本身进入上下文（traces so far）。
  • 终止条件要有"最多 N 步 + 无进展即停 + 拿到足够证据即 Finish"的组合，不能只说"完成任务"。
