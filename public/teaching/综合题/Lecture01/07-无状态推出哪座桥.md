## 一句话回顾

**大模型本身是无状态的** → 直接推出了 **上下文管理（外部状态重放）** 这座桥的必要性：
每次调用把全量历史重新喂进去，用"无状态函数 + 外部状态重放"模拟出"它在记着"。

由"无状态"派生的一整组机制（缺口 → 桥）：
不记上轮 → 会话历史缓冲 · 工具结果会丢 → tool 回填 · 不记进度 → 外部持久化 ·
重启即忘 → 磁盘证据重建 · 跨会话无记忆 → 长期记忆/RAG。
