CS329Z 教学空间

全 11 讲 · 81 课 · 321 道折叠自测 · 每课带 SGRT 工程桥 · 一手来源：lecture/ 下 11 份课件
这是什么：把 Stanford CS329Z（Engineering AI Agents）全部 11 讲课件逐页读完，重写成 81 节中文课程。每节包括：结论先行、机制拆解、数值/代码、失败模式、SGRT 工程桥（映射到你正在做的放疗表面追踪项目）、以及先答再展开的折叠自测。

怎么用：按讲顺序读。每节的自测必须先自己答再展开——这是检索练习，不是阅读（理由见 L01 第 0001 课的 RCT 数据）。每讲最后一节是收官总结，附结业考试题。

  L01 → L05 → L06 → L07 → L08
  → 认识组件、学会工程化、掌握设计模式与记忆、了解多智能体

  L10 → L04（评估部分）→ L09（优化）
  → 评测工程 → 工具使用评估 → 优化策略

  L02 → L09 → L11
  → 模型原理 → 优化 → 数据方案

贯穿全课的四个主线

主线在哪里展开一句话
控制流谱系L01 → L05 → L06程序定步骤（workflow）vs 模型定步骤（agent），真实系统是两者组合
上下文成本L02 → L06O(n²) 是物理约束；五种上下文管理模式按成本递增用
可靠性L01 → L04 → L10错误累积（0.95²⁰≈36%）；Pass^k 而非 pass@k；领域 eval 而非通用榜单
数据与验证L09 → L10 → L11环境在上游（可重复产出）；奖励要客观（Code Tests 优于 LLM 判官）；防奖励黑客
